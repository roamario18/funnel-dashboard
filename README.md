# Дашборд воронки продаж (компетенция «Вайбкод-разработка»)

Приложение показывает аналитику сделок CRM текущего пользователя внутри Битрикс24.

## Сценарии

- Сводка по стадиям выбранной воронки: количество и сумма (`stageId`).
- Выбор воронки CRM (основная и дополнительные).
- KPI: сумма открытых сделок, число выигранных за период, средний чек.
- Последние 20 сделок: название, сумма, стадия, ответственный.
- Фильтр по дате создания: 7 дней / 30 дней / все время.

Работает от лица вошедшего сотрудника (`vibe_app_` + сессия). Ключ и вызовы Vibe API только на сервере (BFF). Секреты в `.env`, не в git.

## Скоупы

| Скоуп | Зачем |
|---|---|
| `crm` | Сделки, стадии, агрегация и поиск |
| `user` | ФИО ответственного |
| `placement` | Пункт левого меню портала |
| `vibe:infra` | Сервер Black Hole и деплой |

`vibe:ai`, `vibe:search`, `vibe:storage` платформа добавляет к ключу авторизации сама. Приложение ими не пользуется.

Режим прав `READWRITE`, т.к. при установке требуется разрешения записать Пункт левого меню (`placement`). 

## Ограничения

- Суммы не приводятся к одной валюте.
- Агрегация ограниченa 5000 записями; при обрезке показывается предупреждение.

- Пустая выборка — empty-state, не ошибка.

## Как проверить

1. Левое меню **«Воронка продаж»** (открывать из меню, не напрямую — иначе Gateway покажет экран Black Hole), https://app-d4c0f00e84c5.vibecode.bitrix24.tech - живой адрес сервера Black Hole, авторизация через Битрикс24. 
2. Сменить фильтр 7 / 30 / все — таблицы и KPI пересчитываются.
3. Сотрудник без CRM должен увидеть понятную ошибку прав.
